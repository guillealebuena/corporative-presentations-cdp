The App's real button, recreated at 2x deck scale for use inside decks/documents.

```jsx
<Button variant="default" icon="ArrowUUpLeft">Volver</Button>
<Button variant="filter" size="sm">Directo</Button>
```

Variants: default (violet fill), secondary (turquoise fill), outline / white-outline / gray-outline (border only), ghost (text only), success / error / warning (semantic fills), filter (pill, for filter chips). `disabled` only visibly changes the outline family (text/border → #A7A7A7).
