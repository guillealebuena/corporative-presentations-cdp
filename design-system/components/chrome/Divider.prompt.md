Thin graphic separator for two data points sharing a line — use instead of writing " · " or " — " as punctuation.

```jsx
<span>Fono Bus<Divider inline />Corredor Sur</span>
```

`inline` = 1×14px vertical hairline, 12px margin each side. Default (no `inline`) = full-width 1px horizontal rule, e.g. under a card-list row.
