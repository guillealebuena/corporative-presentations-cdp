A rounded category pill — used on cover slides ("PROPUESTA COMERCIAL") and section dividers.

```jsx
<Pill tone="brand">PROPUESTA COMERCIAL</Pill>
```

Variants: `tone="soft"` (violet-50 bg, default on white slides), `tone="brand"` (translucent white, for use on the violet cover background), `tone="turquoise"` (accent soft).
