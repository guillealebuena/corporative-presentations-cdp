Solid-fill card dominated by one huge number (140px) — icon badge on top, then the metric, then an uppercase label, optionally a caption line. Distinct from KPIStat's white-background inline use.

```jsx
<MetricCard icon="TrendUp" value="94%" label="Satisfacción" context="vs. trimestre anterior" accent="turquoise" />
<MetricCard icon="Bus" value="4.2x" label="ROI" tone="dark" />
```
