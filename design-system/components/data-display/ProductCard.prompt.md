Recreation of the App's real info card, for showing product mockups inside a deck — distinct from the presentation "Card" benefit-card used in slide grids.

```jsx
<ProductCard badge="promo" title="Buenos Aires → Mar del Plata">Semicama, salida 22:30.</ProductCard>
<ProductCard badge="destacado" title="Vía Bariloche">La más elegida esta semana.</ProductCard>
```
