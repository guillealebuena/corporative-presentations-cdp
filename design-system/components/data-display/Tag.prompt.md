Small status/category chip.

```jsx
<Tag variant="primary-soft">Promo</Tag>
<Tag serviceClass>Cama</Tag>
```

Variants: default (white/gray border), outline (dark border), secondary (turquoise border), expired (solid gray — vencido), primary-soft (soft violet fill). `serviceClass` is a separate pill shape for bus service classes (cama, semicama), not a variant.
